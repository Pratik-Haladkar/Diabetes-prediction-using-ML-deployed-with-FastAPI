# 🩺 Diabetes Prediction using Machine Learning & FastAPI

An end-to-end Machine Learning project that predicts whether a person is diabetic based on medical parameters and exposes the prediction through a REST API built using FastAPI.

This project demonstrates the complete ML workflow — from data preprocessing and model training to API deployment and inference.

---

## 🚀 Project Overview

- Built a Machine Learning model to predict diabetes using clinical features
- Applied feature scaling to ensure consistent model performance
- Deployed the trained model as a RESTful API using FastAPI
- Tested predictions using Swagger UI and a client script

This project is suitable for understanding how ML models are integrated into backend services.

---

## 🧠 Machine Learning Details

- **Algorithm:** Support Vector Machine (SVM)
- **Dataset:** PIMA Indians Diabetes Dataset
- **Preprocessing:** StandardScaler for feature normalization
- **Model Persistence:** Pickle (`.sav` files)
